# Cajathon — Caja Trujillo

Repositorio de evidencias del equipo para la postulación al Cajathon de Caja Trujillo.

Cada integrante documenta aquí el proyecto que usará como respaldo en el formulario de
postulación. Este repositorio es el **enlace de validación** que se adjunta en el campo
*"Enlace a un proyecto, demo o portafolio"*.

---

## Para qué sirve este repositorio

El paso 4 del formulario (*Habilidades*) es **individual**. Cada quien escribe sus propios
textos. Lo que este repositorio aporta es:

1. Un enlace público y verificable que el jurado puede abrir.
2. Capturas y descripciones de las que cada integrante redacta su respuesta.
3. Un formato común, para que las postulaciones del equipo se lean consistentes.

---

## Qué evalúa el formulario

Los textos del paso 4 se califican contra tres habilidades. Toda evidencia debe hablar de
estas tres, no del stack técnico:

| Habilidad | Qué quieren ver |
|---|---|
| Análisis de problemas y procesos de negocio | Que entendiste el problema antes de construir |
| Diseño de soluciones y propuestas de valor | Que la solución responde al problema y a quién sirve |
| Definición de indicadores y evaluación de resultados | Que mediste si funcionó, y con qué |

---

## Cómo subir tu evidencia

1. Copia la carpeta `evidencias/_PLANTILLA/` y renómbrala como `evidencias/<tu-nombre>-<proyecto>/`.
   Ejemplo: `evidencias/step-dashboard-bi/`.
2. Llena el `README.md` de tu carpeta. No borres secciones: si algo no aplica, escríbelo.
3. Pon las capturas en `capturas/` y enlázalas desde tu README.
4. Agrega tu fila a la tabla de abajo.
5. Haz commit y push a `main`.

Lee [CONTRIBUTING.md](CONTRIBUTING.md) antes de subir. Tiene las reglas sobre datos
sensibles y calidad de capturas.

## Reglas rápidas

- **Repositorio público.** No subas datos reales de clientes, credenciales, ni documentos
  internos de ninguna institución. Datos sintéticos o anonimizados únicamente.
- **Honestidad sobre los datos.** Si el proyecto usa datos sintéticos, decláralo. Declararlo
  suma; que lo descubran, resta.
- **Resultados antes que herramientas.** Nadie contrata un stack. Di qué cambió.
